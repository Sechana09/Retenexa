# Model Explainability

## Objective

The objective of this module is to explain the predictions generated by the Random Forest churn prediction model using SHAP (SHapley Additive Explanations).

Explainable AI helps identify which customer characteristics influence churn predictions and provides transparency into individual customer risk assessments.


## Explainability Technique

The project uses SHAP TreeExplainer, which is designed for tree-based machine learning models such as Random Forest. 
SHAP assigns contribution values to individual features, showing how they influence the model's prediction.


## Global Explainability

SHAP values were calculated across the complete dataset of 5,630 customers.

The mean absolute SHAP value was calculated for each feature to determine its overall importance.
The resulting global feature importance was saved as:
`artifacts/shap_global_importance.csv`


## Key Features Influencing Churn

The most influential features identified through SHAP include:

- Tenure
- CashbackAmount
- LoyaltyLevel
- Complain
- AverageSpendPerOrder
- CashbackPerOrder
- WarehouseToHome
- DaySinceLastOrder
- NumberOfAddress
- OrderAmountHikeFromlastYear

These features had the greatest overall influence on the Random Forest churn predictions.


## Individual Customer Explanation

The Streamlit dashboard provides a customer-level SHAP waterfall plot.

Users can search for a Customer ID and view:

- Churn probability
- Risk level
- Features increasing churn risk
- Features decreasing churn risk
- Relative influence of individual features

The individual SHAP calculation is performed only for the selected customer, allowing the dashboard to remain responsive.


## SHAP Waterfall Interpretation

Red features push the prediction toward higher churn risk.

Blue features push the prediction toward lower churn risk.

Larger SHAP contributions indicate stronger influence on the prediction.


## Business Benefits

Explainable AI provides several benefits:

- Improves model transparency.
- Helps understand individual churn predictions.
- Supports data-driven retention decisions.
- Builds trust in machine learning predictions.
- Enables more personalized retention strategies.


## Conclusion

SHAP provides both global and local explanations of the Random Forest churn model.

Global explanations identify the major drivers of churn across the customer base, while individual explanations help retention teams understand why a particular customer has been classified as a churn risk.
